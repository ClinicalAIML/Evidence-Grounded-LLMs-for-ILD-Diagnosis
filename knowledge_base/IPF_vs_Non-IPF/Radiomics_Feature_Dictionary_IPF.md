# Radiomics Feature Dictionary for IPF vs Other

This file is built from a broader supporting-feature literature layer.
It is intended to help interpret radiomics-based report summaries for IPF vs Other ILD.

## General principles
- Interpret radiomics as a pattern, not as isolated markers.
- Distinguish carefully between IPF-specific evidence and non-specific fibrotic ILD evidence.
- Supporting studies can help interpret patterns, but should not overrule direct comparator studies.
